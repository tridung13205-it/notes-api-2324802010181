2. Năm đặc tính NIST qua trải nghiệm thực tế

  1. Tự phục vụ theo yêu cầu: Tôi tự tạo Codespace từ repository GitHub trong vài thao tác, không cần quản trị viên cấp máy.
  2. Truy cập mạng rộng: API chạy trên port 3000 có thể truy cập bằng URL HTTPS từ máy tính và điện thoại.
  3. Gộp tài nguyên: Codespace được GitHub cấp phát từ hạ tầng dùng chung; hostname của môi trường là codespaces-e298bb.
  4. Co giãn nhanh: Có thể tạo, dừng hoặc tạo lại Codespace nhanh theo nhu cầu học tập.
  5. Dịch vụ đo lường được: GitHub ghi nhận số core-hours và dung lượng Codespaces trong mục Billing Usage.

3. Kết quả API

Endpoint GET / trả về JSON có các trường host, cpus, memoryGB, uptimeSec và time.

4. Câu hỏi phản biện

Câu 1

Sau khi Stop rồi Start lại Codespace, trường host có thể thay đổi. Điều này cho thấy môi trường được cấp phát động từ một kho tài nguyên chung, không phải một máy vật lý cố định của riêng sinh viên.

Câu 2

GitHub Codespaces gần với PaaS cho người học: GitHub quản lý hạ tầng, máy chủ và môi trường nền; sinh viên quản lý mã nguồn, thư viện của dự án và ứng dụng Node.js. Codespaces cũng có một số đặc điểm IaaS vì người dùng được dùng Terminal và tùy chỉnh môi trường.

Câu 3

Cách cài môi trường trên từng máy phòng lab mất thời gian và dễ bị khác phiên bản phần mềm giữa các máy. Codespaces tạo môi trường thống nhất từ repository nhanh hơn. Rủi ro mới là phụ thuộc Internet, tài khoản đám mây và nguy cơ lộ thông tin nếu mở port Public hoặc commit tệp chứa khóa bí mật.
